# Roteiro de demo — 75 segundos

1. **0–10s — Problema**: “Uma curva de caixa sem teste não demonstra previsão confiável. Esta etapa separa histórico, previsão e cenário.”
2. **10–25s — Dados seguros**: mostrar o aviso de dados sintéticos e o card de saldo. “A demo usa 180 dias sintéticos, identificados como tal; não há dado financeiro real.”
3. **25–45s — Evidência**: mostrar a seção *Baseline vs. modelo*. “Os 28 últimos dias foram reservados para teste. Comparamos MAE, WAPE e a cobertura do intervalo; não uso percentual de acerto sem contexto.”
4. **45–60s — Incerteza**: apontar a faixa azul e a linha de reserva. “A faixa vem dos resíduos no teste: ela comunica incerteza observada, não uma garantia.”
5. **60–75s — Cenário**: reduzir recebimentos, acrescentar uma saída pontual e clicar em *Simular cenário*. “Agora é uma simulação de premissas, claramente separada da previsão.”

Fechar com: “O próximo passo é importar uma base real com governança e repetir a validação temporal antes de qualquer uso operacional.”
